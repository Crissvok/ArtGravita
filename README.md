# ArtGravita
ArtGravitas — это адреналиновый скоростной-Платформер с элементами головоломок и раннеров, где главная задача игрока — добежать до безопасной зоны для достижения собственных целей, обусловленных нарративом. Игра сочетает физику, инструментарий игрока и постоянное ощущение паники в перемешку со спокойностью между экранами.
